适用游戏版本：Dwarf Fortress Steam 53.17 / 53.16 与官网免费版 53.17 / 53.16。
Byayoi 同人社区：https://byayoi.org/

本包版本：v53.17-20261113。完整更新说明见压缩包根目录 CHANGELOG.txt。

一、GitHub 整包安装

将压缩包中的全部内容按原有目录结构解压到游戏根目录，也就是包含
Dwarf Fortress.exe 的目录。安装后的主要文件位置为：

游戏根目录/dfhooks.dll
游戏根目录/dfhooks_dfcn.ini
游戏根目录/dfcn/dfhooks_dfcn.dll
游戏根目录/dfcn/dfcn_core.dll
游戏根目录/dfcn/data/runtime/

保留完整 dfcn 文件夹及其下的词表、规则、OpenCC 词典、读音数据和许可文件。
dfhooks_dfcn.ini 第一行已经设为 dfcn/dfhooks_dfcn.dll，整包安装无需修改。
汉化设置优先读取游戏根目录/dfcn_config.ini。首次启动时若文件不存在，
从 dfcn/data/runtime/config.ini 复制生成，已有文件不会覆盖。
dfcn/data/runtime/config.ini 保留为默认模板，复制失败时作为回退配置。
无需编译，无需安装 DFHack，也无需在创建世界时启用本汉化。

本文件说明 GitHub 整包安装。Steam 创意工坊安装方式见本体工坊页面：
https://steamcommunity.com/sharedfiles/filedetails/?id=3811193379
若此前使用工坊路径安装，整包安装时采用本包的 dfhooks_dfcn.ini。
从旧版升级时，移除游戏根目录中旧版 dfhooks_dfcn.dll（若存在），
使用 dfcn 文件夹内的加载器。更新时保留游戏根目录的 dfcn_config.ini；
旧版 config.ini 中需要保留的个人设置可写入该文件。

二、开关与数据刷新

Shift+F1：打开或关闭汉化设置菜单，可切换中英文、繁简体、四族语言音译，
开关已安装的 DFHack、重新载入核心与数据并开启汉化，或导出整张地图的全部已知层。
英文模式下仍可打开。切换与重载选项执行后自动关闭，导出选项显示结果和文件位置。
也可按 Esc、右键或点击菜单外空白处关闭。
蓝图保存至汉化目录的 blueprints 文件夹，可导入 dfbluepaint；仅导出地形，不含建筑、物品或单位。
四族语言默认采用中文音译，可切换为原文拼写，选择在本次运行及核心重载后保留。
DFHack 选项需已安装 DFHack 且接口可用。
Shift+F10：开启或关闭汉化，保留当前核心与已加载数据。
Shift+F5：关闭汉化；再按一次开启时重新读取核心与数据。
Shift+F6：临时停用或恢复全部扩展 TSV 词表和 TOML 规则，立即重新载入汉化并开启显示。
扩展默认启用；停用时继续使用本体汉化。左右 Shift 均可，长按不重复切换。
扩展开关只影响本次运行，跨 Shift+F5 重载保留，不写入配置文件。
Shift+F8：在简体中文与台湾正体中文之间切换，同步刷新字体和译文排版。
左右 Shift 均可，长按不重复触发；语言选择在本次运行及核心重载后保留，
不改写配置文件，也不改变汉化显示开关。
默认语言由游戏根目录 dfcn_config.ini 中的 language 配置决定：
language=zh-Hans 为简体中文（默认），language=zh-Hant 为台湾正体中文，
通过随包提供的离线 OpenCC 转为台湾字形及常用词汇。
修改此项可保留默认语言选择；也接受 zh-CN、zh-TW、zh-Hans-CN、zh-Hant-TW。
用户自定义小队名称和用户输入保持原样。
Ctrl+Shift+F10：显式刷新汉化配置、词表和规则。
汉化资源在启动或上述显式刷新时读取。

三、独立汉化数据扩展

核心可自动识别已下载的工坊汉化数据扩展，以及游戏 mods 和
data/installed_mods 中的本地数据包。数据包无需加入创建世界的
模组加载顺序，不修改原始模组 RAW 或世界规则。

独立数据 ZIP 中的整个 mod 文件夹解压至游戏 mods 目录即可。
原始玩法模组仍按其作者说明使用。数据包安装、更新或移除后，
核心在下一次启动或显式重新加载数据时处理变化。
扩展格式与使用说明见 dfcn/docs/translation-extensions.zh-CN.md。
语义搜索模型另有独立的 DFCN Semantic Search Model mod；安装或订阅后，核心会在启动时自动发现并载入。模型不随 DFCN 汉化核心包发布；未安装该 mod 时拼写和拼音搜索仍可使用。
模型订阅：https://steamcommunity.com/sharedfiles/filedetails/?id=3823451988
用户自定义小队名称始终原样显示，包括英文、数字组合和中文。

四、卸载与许可

安装添加汉化自身文件，不修改游戏 RAW 或存档。
卸载时移除自己安装的 dfhooks.dll、dfhooks_dfcn.ini、dfcn_config.ini 及 dfcn 文件夹；
保留游戏本体、RAW、存档和个人资料。需要保留的汉化设置先自行保存。
