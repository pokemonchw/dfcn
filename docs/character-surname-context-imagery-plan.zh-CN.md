# 英文复合姓氏全量词汇分类与搭配意象方案

日期：2026年10月9日。状态：全量义项分类、单字双字命名词形和双向类别差分已接入。本文描述当前数据与选词规则，不表示已观察到游戏内最终显示。

## 全量范围与明确要求

当前姓氏词表包含 5,927 个英文词形、7,606 个义项，使用 288 个语义类别；上下文词形表包含 744,919 条分支，构词表包含 142 条关系记录。

用户要求所有意象、所有组合情形都具有独立编写的单字和双字命名词。每条上下文分支都同时提供 `single` 与 `double`，不能以“无法凝练”、禁用词形或解释长句作为已经完成的例外。整个词表都执行类别差分，不能只修改苹果或少数截图词。

原有普通词义、具体种类、单位和身份仍保存在基础词表的 `full_meaning`、`identity` 等字段。命名上下文另造短词，不用“早晨的景象”“眼镜蛇的鳞片”等说明短语充当姓氏词形，也不机械拼接“词素＋象／意／质”冒充造词。按当前要求，六份姓名与姓氏词表中的 `notes`、`semantic_bridge`、`description` 注解内容已清空；空列保留以兼容现有格式，加载器不再要求注解非空。

## 分类与双向差分

每个义项分别记录语法身份、主要语义类别和可参与搭配的属性。一个义项使用一个主要类别；附属标签与必要属性用于细化已有语义关系，不从人物的职业、经历、种族或性格推导姓氏。

分类细分金属矿物、油脂附着物、木材纤维、食物饮料、果实种子、植物部位、生物、身体和体液、武器防具、工具容器、衣物、建筑设施、地形水域、天体天气、光暗时间、声音表达、人物身份、社会制度、情绪品德、魔法、生死损毁、物理性质、数量位置和思维概念。神圣与亵渎、疾病与普通生命状态、疫病与一般疾病、货币价值与普通交易分别分类。

动作同时记录及物或不及物配价、允许的对象或主体类别；状态保留过程、结果等区别。上弦仍是加工动作，不变成天气意象。明确的施事身份保存自己的词干和完整身份，普通动作不能凭空补成某种职业或“者”。

对于每一对已识别义项，两端都按“自己的义项＋对方类别＋关系＋角色”查找短词。苹果面对神圣、防具与食物会选择不同命名词；搭配词也必须反过来按苹果的类别选择自己的分支。只给一端作差分、另一端始终沿用通用词形，不满足这项要求。

细类词形逐类登记。含义、词形和用途一致的细类可以显式共享同一条记录；类别差分体现实际不同的语义侧面与命名词，不能只复制词形再更换类别标签。已删除 `nominal_image` 通用分支；旧 `compact`、`balanced`、`preferred` 等通用形态不能绕过具体上下文分支再次进入候选。

## 单字和双字造词

单字是该分支独立编写的命名词素，双字是该分支独立编写的短命名词。两种长度可以有多个候选，不要求开头相同，也不能先拼出双字再机械抽取第一字。较长来源词仍保留普通本义，命名场景另外登记短词。

苹果的类别差分如下。表中只表示苹果端的词形，对方另选自己的分支。

| 对方类别 | 单字命名词 | 双字命名词 |
| --- | --- | --- |
| 神圣 | 祉 | 灵苹 |
| 疾病 | 蚀 | 蠹苹 |
| 护具 | 核 | 坚苹 |
| 食物 | 甘 | 脆苹 |
| 地形 | 隆 | 苹丘 |
| 货币 | 馈 | 珍苹 |

较长来源词也提供命名短词。例如下列词形仍保留各自的原始来源义项，其他类别分支继续独立登记。

| 来源义项 | 单字命名词 | 双字命名词 |
| --- | --- | --- |
| 早午餐 | 晏 | 晏餐 |
| 常春藤 | 常 | 常蔓 |
| 眼镜蛇 | 镜 | 镜虺 |
| 威士忌 | 酒／忌 | 忌酿 |

这些是命名词形，不改变普通界面中早午餐、常春藤、眼镜蛇或威士忌的翻译。疾病意象用于命名，不断言持名者生病；防御、地形、价值等意象也不能加入人物经历、现实财产或具体事件。

意象类型分为 `direct` 直接保义与 `property` 属性凝练。属性凝练仍受来源义项、适用类别和构式限制，语义损失继续参与评分；不要求另填说明注解。`bound` 表示适用于已登记构词关系的词素，不因无法独立成词而统一压低；`restricted` 继续保留真实的语义和构式限制。

## 组合关系与候选

| 组合关系 | 选词职责 |
| --- | --- |
| 性质修饰 | 性质端按对象类别选词，中心词按修饰性质选自己的分支 |
| 材质修饰 | 区分材料本体、材质、颜色及象征，不互换义项 |
| 表面与附着 | 区分材料、体液本体、附着和质感 |
| 自然徽记 | 两端保留已登记的意象，不加入人物经历 |
| 动宾 | 谓词符合自身配价，对象使用相应受事分支 |
| 主谓 | 主体类别符合动作要求，动作使用相应谓词分支 |
| 施事构词 | 真正的施事身份按原来源顺序使用登记词干和“者”构式 |
| 所属、来源与独立命名 | 两端按类别选词，再比较正序、倒序与“之”结构 |
| 并列 | 已登记的词素和属性命名词可以参与；真实 `restricted` 限制仍保留 |
| 前缀修饰 | 前缀保留数量、否定、程度、位置等语法作用 |

普通复合姓氏共同比较以下方案：

- `A+B`、`B+A`。
- `A+之+B`、`B+之+A`。
- `AA+之+B`、`BB+之+A`。
- `AABB`、`BBAA`。

A、B 表示各自独立登记的单字词形；AA、BB 表示各自独立登记的双字词形。还包括 `1＋2`、`2＋1` 的直接组合，以及允许的对应“之”字组合；普通组合不要求等宽。复合姓氏内部不插入分隔符或“与”。真实施事身份保持原有身份许可和两根一字加“者”的构式。

运行时先沿用已有英文识别与可信拆分边界，再分别匹配两端的主要类别、必要属性和角色。具体细类优先于明确登记的上层类别，必要属性更具体的分支优先；不为得到短名另造词根或换成错误义项。同级、同样适用的分支全部保留候选，不再按分支偏好提前淘汰词形。七种宽度模式按允许的双向顺序共同参与选择，不固定优先单字＋单字或双字＋双字。

候选先满足关系、配价、角色与用途限制，再共同比较自然构词、保义、词汇完整性和读音。姓名调用继续抵消共享读音模型中无连接双字＋双字的固定加分，完整单字本义与完整双字本义获得同等词汇证据；自然 `bound` 词素也不再承受固定的百万级减分。

自然词证据索引只收录基础义项的 `full_meaning` 与 `identity`，使用自有字符串保存。索引只评价已经匹配的上下文候选，不产生额外候选，也不把普通本义回灌进类别分支。候选等于自己的完整本义或身份时得到较强词汇证据；`core`、`head`、`modifier`、`action`、`agent` 的命中提供较弱的角色适配证据。命中全库其他完整词只能说明这个表达有普通词汇依据，不能据此认定它保留了当前义项的含义。

两个非独立的 `bound`、`restricted` 或 `stem` 词素直接相接时，若没有连接词，也不属于明确施事、动宾、主谓或前缀关系，组合承担小而有界的语义不透明代价。该代价来自组合解释不足，不根据 `11` 或 `22` 固定施加。“之”可以标明两端的关系边界，不能免除单个词形自身的词汇不足或语义限制。

主体分数使用统一的有限权重：`rule.naturalness * 4 + preservation * 6 + lexical * 4 + clamp(pronunciation, -48, 12) * 2`。不再使用百万级自然度、十万级保义等排序层，也不在主体分数中扣字数。仅当主体同分时，先比较 `preference`，再比较长度。这样所有合法结构都依据整体自然度与顺口程度竞争，偏好与简练程度不能预先决定赢家。本轮调整选词机制，保留现有词形数据。

| 文件 | 当前职责 |
| --- | --- |
| `data/runtime/character-name-lexicon.tsv` | 既有英文识别词形、义项、词性及状态 |
| `data/runtime/character-surname-lexicon.tsv` | 主要类别、属性、基础短词、完整普通本义、身份及共享来源 |

上下文表使用以下字段：

| 字段 | 含义 |
| --- | --- |
| `english kind category state sense` | 完整来源义项键 |
| `relation self_role` | 构词关系与自己的角色 |
| `partner_class partner_traits` | 对方类别与必要属性 |
| `single double` | 该分支独立编写的单字与双字候选 |
| `single_use double_use` | 命名词素、自然词、活动名词等用途及真实构式限制 |
| `single_interpretation double_interpretation` | 直接保义或属性凝练 |
| `semantic_bridge` | 已清空，保留空列以兼容现有格式 |
| `construction` | 允许的单字、双字构式 |
| `preference` | 分支偏好 |
| `notes` | 已清空，保留空列以兼容现有格式 |

上下文不再包含 `full`、`full_use`、`full_interpretation` 列。构词 `forms` 只使用 `11`、`12`、`21`、`22`、`11z`、`12z`、`21z`，已经删除 `full`、`fullz`。长本义与说明短语不能参加分类命名候选竞争。

构词表的 `context_relation` 指定来源分支。独立命名使用 `class_image` 的具体类别分支；活动名词 `nominal` 不能作为动宾或主谓中的谓词。原有明确施事身份、动作配价和真正 `restricted` 的使用条件继续生效，不以全量造词为由改变这些语法含义。

每个词形分支只保存一次，义项和类别索引引用同一记录。分支构式使用七位掩码；用途与解释标签引用静态字面量，避免每行复制多组字符串。基础完整词的自然度证据索引随同一批资源建立，保存自有字符串；它不引用加载中的临时行或词干临时值。运行时只取实际匹配的短词候选，不遍历全表。资源更新沿用既有读取和姓氏缓存清理路径。

Git 仓库通过 Git LFS 保存完整的 `character-surname-context-imagery.tsv`。获取源码时需安装 Git LFS 并取回该文件；运行时和安装包继续使用同一路径下的完整 TSV 数据。

识别回退保持既有范围。确实未选出已许可的组合时，最后的低分路径可保留两端完整已知本义，避免丢失已经识别的中文；它不参加短词候选竞争，也不作为“该分支不用造词”的交付例外。独立单根名称和普通词义继续使用自己的完整本义或身份。

## 适用范围与交付

本轮交付涵盖全量义项分类、全部类别分支的双长度命名词、双向选词、混合长度与“之”字构式，以及相应资源加载代码。类别差分适用于整份词表，不新增特定截图整名的硬编码。

地点、势力等已有名称入口同样读取双向类别差分词形与有限自然度评分，保留各自的实体构词约束、实体复合名的等宽形态和整名音译回退，不使用旧固定短词或单字组合的分级优先。实体复合名内部不添加人名的“之”或“者”；原有完整名称中的所属关系和称号仍由实体分组语法处理。命名词形不扩散到普通界面翻译。原生语言音译、完整身份和英文释义姓氏继续按来源区分。用户自定义 `squad.alias` 原样显示，已有明确整名词条保留专名依据。

个人名字优先使用已确认的原生音译，不因英文显示词能够拆成两个姓氏词根而转入意译。原生姓名与英文释义成对显示时，释义中的首名沿用同一原生音译，剩余姓氏才进入姓氏构词；真正昵称的内容和其后的姓氏分别处理。

没有独立 `first_name`、首个可见名字由原生词根生成的人物，同样沿用该名字的原生音译。历史事件保存原生姓名来源，人物详情标题和页签使用已确认的人物身份，与正文共用人物名译法；普通地点和物品名称继续使用各自的入口。
