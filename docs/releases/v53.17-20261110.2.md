# DFCN v53.17-20261110.2

相较于 [v53.17-20261110](https://github.com/pokemonchw/dfcn/releases/tag/v53.17-20261110)，本版包含其后 5 次修复提交。

- 修复冒险模式绑架传闻对话漏译，按实际句式匹配时间、人物、地点与绑架者，保留动态信息。
- 补齐要塞模式与冒险模式音频设置中的“界面音量”标签翻译，保留音量百分比，并将标签纳入音频设置的左对齐布局。
- 修复 Dwarf Fortress 53.17 公告设置页的原生控件绑定遗漏，同时补齐旧地址缓存所需的控件覆盖。
