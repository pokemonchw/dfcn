[NAME:DFCN - Chinese Localization]
[DESCRIPTION:Windows x64 localization for Dwarf Fortress, supporting Steam 53.17 / 53.16 and Classic 53.17 / 53.16. Shift+F1 opens or closes the translation settings menu: toggle Chinese/English, Simplified/Traditional Chinese, original spelling/Chinese transliteration for the four races' languages, installed DFHack, reload the translation core and data, or export terrain blueprints for the whole local map across all known levels. Chinese transliteration is enabled by default; the selection lasts for the current session, including core reloads. Blueprints preserve coordinates, mark unrevealed cells, and exclude buildings, items, and units. They are saved in the translation directory under blueprints and can be imported into dfbluepaint. The menu also works in English mode; Esc or right-click closes it. Shift+F8 switches Simplified Chinese and Taiwan Traditional Chinese using bundled offline OpenCC. The choice lasts for the current session, including core reloads. Set language=zh-Hans or language=zh-Hant in the game directory's dfcn_config.ini for the default language; this file is created from the bundled config.ini if absent. Run install.bat once to automatically find the Windows game directory and install the bootstrap with the correct Workshop path. Supports multiple Steam libraries and preserves dfcn_config.ini. Keep the complete DFCN folder in the subscription directory for Steam updates. Automatically discovers separate translation data extensions and the optional semantic-search model mod. Semantic search is active only when that independent model mod is installed. The optional Map Preview switch appears only while the independent map-preview Workshop mod is subscribed to and installed. No DFHack dependency. See INSTALL.txt.]
