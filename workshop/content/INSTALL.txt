DFCN · 矮人要塞简体中文汉化
Byayoi 同人社区：https://byayoi.org/
GitHub：https://github.com/pokemonchw/dfcn
Releases：https://github.com/pokemonchw/dfcn/releases

当前工坊版本：53.16-20261010（2026-10-10）。完整更新日志见本目录 CHANGELOG.txt。
适用：Dwarf Fortress 53.16，Windows x64；支持 Steam 版与官网免费版。
运行文件位于 DFCN/。Shift+F6 可临时停用或恢复扩展数据；Shift+F5 再次开启时重新读取核心与数据。
仅订阅不会自动启用汉化；无需在创建世界时启用本工坊项目。

一、Windows 工坊安装

订阅内容目录：
你的 Steam 库目录\steamapps\workshop\content\975370\3811193379\DFCN\

游戏根目录（包含 Dwarf Fortress.exe）：
你的 Steam 库目录\steamapps\common\Dwarf Fortress\

1. 订阅并等待下载完成后，打开上面的 DFCN 文件夹。
2. 只将 dfhooks.dll 和 dfhooks_dfcn.ini 复制到游戏根目录。
3. 打开游戏根目录中的 dfhooks_dfcn.ini，第一行填写订阅内容里 dfcn/dfhooks_dfcn.dll 的实际路径。
   其他文件继续保留在订阅目录中，无需复制整个 DFCN 或 dfcn 文件夹到游戏目录。

游戏与订阅内容位于同一 Steam 库时，dfhooks_dfcn.ini 已预填以下相对路径，可直接使用：
../../workshop/content/975370/3811193379/DFCN/dfcn/dfhooks_dfcn.dll

例如你的 Steam 库在 D:\SteamLibrary，游戏程序为：
D:/SteamLibrary/steamapps/common/Dwarf Fortress/Dwarf Fortress.exe
汉化加载器为：
D:/SteamLibrary/steamapps/workshop/content/975370/3811193379/DFCN/dfcn/dfhooks_dfcn.dll

也可以将 dfhooks_dfcn.ini 的第一行直接写为以上汉化加载器的绝对路径。
如果 Steam 使用默认安装目录，第一行示例为：
C:/Program Files (x86)/Steam/steamapps/workshop/content/975370/3811193379/DFCN/dfcn/dfhooks_dfcn.dll

按自己的实际 Steam 库位置修改盘符和目录。游戏与订阅内容在不同 Steam 库时，使用订阅内容的绝对路径。
第一行只写 DLL 路径，不加引号，不写 key=value；保存为 UTF-8 无 BOM。
路径末尾包含 dfhooks_dfcn.dll 文件名。它自动加载同目录的 dfcn_core.dll，并读取该目录的 data/runtime 词表、规则与设置。请保留订阅目录中的完整结构。

注意两个配置文件的用途：
- 游戏根目录中的 dfhooks_dfcn.ini：用于指定加载器 DLL 的路径。
- 汉化设置 config.ini：留在订阅目录，不复制到游戏目录。位置为：
  你的 Steam 库目录\steamapps\workshop\content\975370\3811193379\DFCN\dfcn\data\runtime\config.ini

Windows 运行包默认 font_scale=1.1、min_font_pixels=12、font_bold=true；font_pixel_grid=0 保留普通字体渲染，使用点阵字体时可设为 12 启用整数倍缩放。完整设置说明见 config.ini。
后续 Windows 工坊更新由 Steam 下载到订阅目录；只要实际目录不变，游戏中的入口配置继续指向该目录。

从旧版 Windows 整包复制方式升级：
移除游戏根目录中旧版汉化的 dfhooks_dfcn.dll（若存在），避免加载两份汉化。
旧版复制到游戏目录中的 dfcn 文件夹已不再使用，可在保留个人配置或资料后移除。

二、GitHub Release 安装

https://github.com/pokemonchw/dfcn/releases/tag/v53.16-20261010
下载 DFCN-Windows-x64-minimal.zip，将全部内容按原目录结构解压到包含 Dwarf Fortress.exe 的游戏根目录。
包括 dfhooks.dll、dfhooks_dfcn.ini 和整个 dfcn 文件夹；汉化设置位于游戏目录的 dfcn/data/runtime/config.ini。
此包的入口配置指向游戏目录中的 dfcn/dfhooks_dfcn.dll，不使用工坊相对路径。

三、独立汉化数据扩展

核心在启动或显式重新读取数据时，识别已下载的工坊汉化数据扩展及游戏 mods、data/installed_mods 中的本地数据包。
汉化数据包无需在创建世界的模组列表中启用；原始玩法模组按其作者说明使用。
本体运行包不合并独立数据扩展或原始玩法模组，不修改原模组 RAW 或世界规则。

四个公开汉化数据包分别提供：
Dwarvemon 2.22 基础汉化：
https://steamcommunity.com/sharedfiles/filedetails/?id=3815355177
Dwarvemon Beta 2.22 及随包可选模块汉化：
https://steamcommunity.com/sharedfiles/filedetails/?id=3815791420
Dwarvemon Entity All 2.22 名称与文明配置简介汉化：
https://steamcommunity.com/sharedfiles/filedetails/?id=3815791319
Dwarvemon Entity Type 2.22 名称与文明配置简介汉化：
https://steamcommunity.com/sharedfiles/filedetails/?id=3815791235
Entity All、Entity Type 的生物和物品译文需配合 Dwarvemon 汉化数据。
四个包分别订阅或安装，宝可梦专用词条保存在各自的独立数据包中。
工坊订阅后自动识别，无需复制其中的数据到本体目录。
GitHub v53.16-20261010 同时提供这四个包的独立 ZIP，整个 mod 文件夹解压至游戏 mods 目录即可。
其余 18 个汉化数据包保持私密。
模组名称和内容使用通用译文匹配，没有完整译文的名称及简介保留原文；用户自定义小队名称始终原样显示。
其他汉化扩展的安装与支持范围以各自说明为准。

四、汉化开关与数据刷新

Shift+F10：开启或关闭汉化，保留当前核心和数据。
Shift+F5：关闭汉化；再次开启时重新读取核心和数据。
Ctrl+Shift+F10：显式刷新配置、词表和规则数据。
核心不自动检查文件变化；数据在启动、Shift+F5 重新开启或显式刷新时读取。

Shift+F6：首次按下停用全部扩展 TSV 词表和 TOML 规则，立即重新载入本体汉化并开启显示；再次按下恢复扩展并重新载入汉化。
扩展默认启用，左右 Shift 均可，长按不重复切换。扩展开关只影响本次运行，跨 Shift+F5 重载保留，不写入配置文件。

Windows 同时安装 DFHack 53.16-r2 时，可按 Shift+F11 独立暂停或恢复 DFHack 工具。
插件配置和状态会保留；关闭时已经打开的 DFHack 界面会关闭，此前对游戏或存档执行的修改不会回滚。
汉化覆盖 DFHack 帮助、控制面板、常用弹窗及本地命令输出，可执行命令、快捷键和导出内容保留原文。

五、卸载

取消订阅不会自动删除手动复制到游戏目录中的文件。
Windows 工坊安装：删除自己添加到游戏根目录的 dfhooks.dll 和 dfhooks_dfcn.ini，再取消订阅。
Windows GitHub 整包安装：移除自己安装的入口文件及 dfcn 汉化目录。
旧版整包安装遗留的汉化文件也需自行移除。无需删除游戏本体或存档。

本项目不会破坏或改写磁盘上的游戏本体文件，不修改游戏 RAW 或存档。
没有 DFHack 或其他外部 Mod 依赖。
