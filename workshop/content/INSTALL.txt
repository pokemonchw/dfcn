Byayoi 同人社区：https://byayoi.org/
GitHub：https://github.com/pokemonchw/dfcn
Releases：https://github.com/pokemonchw/dfcn/releases

当前工坊版本：53.17-20261111（2026-11-11）。完整更新日志见本目录 CHANGELOG.txt。
适用：Windows x64，Dwarf Fortress Steam 53.17 / 53.16 与官网免费版 53.16。
运行文件位于 DFCN/。Shift+F6 可临时停用或恢复扩展数据；Shift+F5 再次开启时重新读取核心与数据。
首次订阅后运行 install.bat 自动安装引导；无需在创建世界时启用本工坊项目。
汉化数据扩展与可选语义搜索模型均为独立 mod，会在启动时自动识别；模型不包含在本工坊核心包内。
可选模型订阅：https://steamcommunity.com/sharedfiles/filedetails/?id=3823451988

一、Windows 工坊安装

订阅内容目录：
你的 Steam 库目录\steamapps\workshop\content\975370\3811193379\

游戏根目录（包含 Dwarf Fortress.exe）：
你的 Steam 库目录\steamapps\common\Dwarf Fortress\

1. 订阅并等待下载完成后，双击订阅目录中的 install.bat。
2. 脚本自动查找 Steam 游戏目录，复制引导文件并填写汉化路径。显示“安装完成”后即可正常启动游戏。
   不用手动复制文件或编辑 INI，不依赖 DFHack；使用 Windows 自带 PowerShell。
3. 完整 DFCN 文件夹继续保留在订阅目录，后续核心与词表由 Steam 更新。

脚本支持中文路径和多个 Steam 库，优先选择与订阅内容同库的游戏。
如果发现多个游戏目录且无法唯一确定，会显示目录供选择。
也可以单独下载 install.bat 运行，脚本会查找已经下载的工坊汉化文件。
官网版或其他未被自动找到的游戏，可将游戏文件夹或 Dwarf Fortress.exe 拖到 install.bat 上，
或使用：install.bat "D:\Games\Dwarf Fortress"
脚本仍需要已下载的工坊汉化内容，或与脚本相邻的完整 DFCN 文件夹。
已有 dfcn_config.ini 不会改写。被替换的引导文件保留为 .dfcn-backup- 开头后缀的备份，
旧版根目录 dfhooks_dfcn.dll 同样改名备份以避免重复加载，不删除旧 dfcn 目录。
安装失败会尝试恢复本次已经改动的文件，并显示具体错误与无法恢复的备份位置。
如果使用解压到其他位置的 DFCN 文件夹，该文件夹也必须保留；移动目录后重新运行脚本。

手动安装备用方式：将 DFCN 中的 dfhooks.dll 和 dfhooks_dfcn.ini 复制到游戏根目录，
再将游戏根目录 dfhooks_dfcn.ini 的第一行改为实际加载器路径。以下示例仅供手动安装参考；
install.bat 会自动填写绝对路径，无需再修改。

游戏与订阅内容位于同一 Steam 库时，dfhooks_dfcn.ini 已预填以下相对路径，可直接使用：
../../workshop/content/975370/3811193379/DFCN/dfcn/dfhooks_dfcn.dll

例如你的 Steam 库在 D:\SteamLibrary，游戏程序为：
D:/SteamLibrary/steamapps/common/Dwarf Fortress/Dwarf Fortress.exe
汉化加载器为：
D:/SteamLibrary/steamapps/workshop/content/975370/3811193379/DFCN/dfcn/dfhooks_dfcn.dll

也可以将 dfhooks_dfcn.ini 的第一行直接写为以上汉化加载器的绝对路径。
如果 Steam 使用默认安装目录，第一行示例为：
C:/Program Files (x86)/Steam/steamapps/workshop/content/975370/3811193379/DFCN/dfcn/dfhooks_dfcn.dll

按自己的实际 Steam 库位置修改盘符和目录。游戏与订阅内容在不同 Steam 库时，使用订阅内容的绝对路径。
第一行只写 DLL 路径，不加引号，不写 key=value；保存为 UTF-8 无 BOM。
路径末尾包含 dfhooks_dfcn.dll 文件名。它自动加载同目录的 dfcn_core.dll，并读取该目录的 data/runtime 词表、规则与 OpenCC 词典。请保留订阅目录中的完整结构。

注意配置文件的用途：
- 游戏根目录中的 dfhooks_dfcn.ini：用于指定加载器 DLL 的路径。
- 游戏根目录中的 dfcn_config.ini：用于汉化设置，启动时优先读取。
- 订阅目录中的 config.ini：用于默认模板，位置为：
  你的 Steam 库目录\steamapps\workshop\content\975370\3811193379\DFCN\dfcn\data\runtime\config.ini
首次启动时若游戏根目录没有 dfcn_config.ini，会从该默认模板复制生成；已有文件不会覆盖。
模板保留在订阅目录，复制失败时作为回退配置。

Windows 运行包内置思源黑体简体粗体及字体许可，默认 font_scale=1.1、min_font_pixels=16、font_bold=true；font_pixel_grid=0 保留普通字体渲染，使用点阵字体时可设为 12 启用整数倍缩放。个人设置写入游戏根目录的 dfcn_config.ini。
后续 Windows 工坊更新由 Steam 下载到订阅目录；只要实际目录不变，游戏中的入口配置继续指向该目录。

从旧版 Windows 整包复制方式升级：
install.bat 会将游戏根目录中旧版汉化的 dfhooks_dfcn.dll 改名备份，避免加载两份汉化；手动安装时自行移除该文件。
旧版复制到游戏目录中的 dfcn 文件夹已不再使用，可在保留个人配置或资料后移除。
更新时保留游戏根目录的 dfcn_config.ini；旧版 config.ini 中需要保留的个人设置可写入该文件。

二、GitHub Release 安装

https://github.com/pokemonchw/dfcn/releases
下载 DFCN-Windows-x64-minimal.zip，将全部内容按原目录结构解压到包含 Dwarf Fortress.exe 的游戏根目录。
包括 dfhooks.dll、dfhooks_dfcn.ini 和整个 dfcn 文件夹；汉化设置优先读取游戏根目录的 dfcn_config.ini。
首次启动时若文件不存在，从 dfcn/data/runtime/config.ini 复制生成；已有文件不会覆盖，复制失败时读取该默认模板。
此包的入口配置指向游戏目录中的 dfcn/dfhooks_dfcn.dll，不使用工坊相对路径。

三、独立汉化数据扩展

核心在启动或显式重新读取数据时，识别已下载的工坊汉化数据扩展及游戏 mods、data/installed_mods 中的本地数据包。
汉化数据包无需在创建世界的模组列表中启用；原始玩法模组按其作者说明使用。
本体运行包不合并独立数据扩展或原始玩法模组，不修改原模组 RAW 或世界规则。

四个公开汉化数据包分别提供：
Dwarvemon 2.22 基础汉化：
https://steamcommunity.com/sharedfiles/filedetails/?id=3815355177
Dwarvemon Beta 2.22 及随包可选模块汉化：
https://steamcommunity.com/sharedfiles/filedetails/?id=3815791420
Dwarvemon Entity All 2.22 名称与文明配置简介汉化：
https://steamcommunity.com/sharedfiles/filedetails/?id=3815791319
Dwarvemon Entity Type 2.22 名称与文明配置简介汉化：
https://steamcommunity.com/sharedfiles/filedetails/?id=3815791235
Entity All、Entity Type 的生物和物品译文需配合 Dwarvemon 汉化数据。
四个包分别订阅或安装，宝可梦专用词条保存在各自的独立数据包中。
工坊订阅后自动识别，无需复制其中的数据到本体目录。
GitHub Releases 提供这四个包的独立 ZIP，整个 mod 文件夹解压至游戏 mods 目录即可。
其余 18 个汉化数据包保持私密。
模组名称和内容使用通用译文匹配，没有完整译文的名称及简介保留原文；用户自定义小队名称始终原样显示。
其他汉化扩展的安装与支持范围以各自说明为准。

四、汉化开关与数据刷新

Shift+F1：打开或关闭汉化设置菜单，可切换中英文、繁简体、四族语言音译，
开关已安装的 DFHack、重新载入核心与数据并开启汉化，或导出整张地图的全部已知层。
英文模式下仍可打开。切换与重载选项执行后自动关闭，导出选项显示结果和文件位置。
也可按 Esc、右键或点击菜单外空白处关闭。
蓝图保存至汉化目录的 blueprints 文件夹，可导入 dfbluepaint；仅导出地形，不含建筑、物品或单位。
四族语言默认采用中文音译，可切换为原文拼写，选择在本次运行及核心重载后保留。
DFHack 选项需已安装 DFHack 且接口可用。
Shift+F10：开启或关闭汉化，保留当前核心和数据。
Shift+F5：关闭汉化；再次开启时重新读取核心和数据。
Ctrl+Shift+F10：显式刷新配置、词表和规则数据。
核心不自动检查文件变化；数据在启动、Shift+F5 重新开启或显式刷新时读取。

Shift+F6：首次按下停用全部扩展 TSV 词表和 TOML 规则，立即重新载入本体汉化并开启显示；再次按下恢复扩展并重新载入汉化。
扩展默认启用，左右 Shift 均可，长按不重复切换。扩展开关只影响本次运行，跨 Shift+F5 重载保留，不写入配置文件。

Shift+F8：在简体中文与台湾正体中文之间切换，同步刷新字体和译文排版。
左右 Shift 均可，长按不重复触发；语言选择在本次运行及核心重载后保留，不改写配置文件，也不改变汉化显示开关。
默认语言由游戏根目录 dfcn_config.ini 中的 language 配置决定：
language=zh-Hans 为简体中文（默认）；language=zh-Hant 为台湾正体中文，使用随包提供的离线 OpenCC 转为台湾字形及常用词汇。
修改此项可保留默认语言选择；同时接受 zh-CN、zh-TW、zh-Hans-CN、zh-Hant-TW。自定义小队名称和用户输入保持原样。

Windows 同时安装 DFHack 53.16-r2 / r3、53.17-r1 时，可按 Shift+F11 独立暂停或恢复 DFHack 工具。
插件配置和状态会保留；关闭时已经打开的 DFHack 界面会关闭，此前对游戏或存档执行的修改不会回滚。
汉化覆盖 DFHack 帮助、控制面板、常用弹窗及本地命令输出，可执行命令、快捷键和导出内容保留原文。

五、卸载

取消订阅不会自动删除脚本安装或手动复制到游戏目录中的文件。
Windows 工坊安装：删除自己添加到游戏根目录的 dfhooks.dll、dfhooks_dfcn.ini 和生成的 dfcn_config.ini，再取消订阅。
Windows GitHub 整包安装：移除自己安装的入口文件、dfcn_config.ini 及 dfcn 汉化目录。
旧版整包安装遗留的汉化文件也需自行移除。无需删除游戏本体或存档。

本项目不会破坏或改写磁盘上的游戏本体文件，不修改游戏 RAW 或存档。
没有 DFHack 或其他外部 Mod 依赖。
