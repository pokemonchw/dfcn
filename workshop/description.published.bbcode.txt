[h1]DFCN · 矮人要塞简体中文汉化[/h1]

DFCN 是 Byayoi 同人社区的《Dwarf Fortress（矮人要塞）》汉化作品，结合社区译文与本地修订，翻译游戏界面、人物信息、物品描述和传说故事，支持简体中文与台湾正体中文。

[b]适配 Dwarf Fortress 53.16，Windows x64，支持 Steam 版与官网免费版。[/b]
当前版本：[b]53.16-20261031[/b]（2026-10-31）。
游戏内按 [b]Shift+F1[/b] 打开汉化设置菜单，可切换中英文、繁简体、四族语言原文／音译，开关已安装的 DFHack，或重新载入汉化。
更新内容见改动说明与订阅目录中的 CHANGELOG.txt。

[h1]Windows 工坊安装[/h1]

[b]首次订阅后运行 install.bat 自动安装，无需手动复制文件。[/b]
[olist]
[*]订阅并下载完成，打开订阅目录：[code]你的 Steam 库目录/steamapps/workshop/content/975370/3811193379/[/code]
[*]双击 [b]install.bat[/b]，自动寻找游戏目录、安装引导文件并填写汉化路径。
[*]显示安装完成后正常启动游戏。完整 [b]DFCN[/b] 文件夹保留在订阅目录，核心与词表继续由 Steam 更新。
[/olist]
脚本使用 Windows 自带 PowerShell，支持中文路径和多个 Steam 库。官网版可将游戏文件夹或 Dwarf Fortress.exe 拖到 BAT 上。移动安装目录后重新运行脚本；手动安装见 INSTALL.txt。

保留完整订阅目录结构。汉化设置优先使用游戏根目录的 [b]dfcn_config.ini[/b]；首次启动时若该文件不存在，从订阅目录的 [code]DFCN/dfcn/data/runtime/config.ini[/code] 复制生成，已有文件不会覆盖。订阅目录中的 config.ini 保留为默认模板和复制失败时的回退配置。
后续工坊更新由 Steam 下载到订阅目录；目录不变时，入口配置继续使用，个人设置保存在游戏根目录。
脚本备份被替换的引导文件及旧版根目录 [b]dfhooks_dfcn.dll[/b]，保留已有 dfcn_config.ini 与旧 dfcn 文件夹。

[h1]简体与正体切换[/h1]

默认显示简体中文。[b]Shift+F8[/b] 可在简体中文与台湾正体中文之间切换。正体译文使用随包提供的离线 OpenCC，采用台湾字形及常用词汇；自定义小队名称和用户输入保持原样。

左右 Shift 均可，长按不会重复切换。切换时同步刷新字体与译文排版，不改变汉化开关状态；语言选择在本次运行及核心重载后保留，不写入配置文件。

设置默认语言请修改游戏根目录的 [b]dfcn_config.ini[/b]：
[code]language=zh-Hans[/code] 表示简体中文；[code]language=zh-Hant[/code] 表示台湾正体中文。也接受 zh-CN、zh-TW、zh-Hans-CN、zh-Hant-TW。

[h1]GitHub 安装与汉化扩展[/h1]

GitHub Windows 运行包 [b]DFCN-Windows-x64-minimal.zip[/b] 整包解压到游戏根目录，包括 dfhooks.dll、dfhooks_dfcn.ini 和整个 dfcn 文件夹。
汉化设置同样优先使用游戏根目录的 dfcn_config.ini；首次启动由 dfcn/data/runtime/config.ini 复制生成，已有文件不会覆盖。

本体自动识别已下载的独立汉化数据扩展；数据包无需在创建世界的模组列表中启用，原始玩法模组按其作者说明使用。本体运行包不内置独立数据包。

Dwarvemon 与 Beta 各有独立完整数据；Entity Type 与 Entity All 翻译各自名称和文明配置简介，生物与物品译文由 Dwarvemon 汉化数据提供。
Real Book 汉化扩展翻译阅读界面、书名和生成的书籍正文，并附带性能兼容脚本；需要安装 Real Book/Scroll Content! 原模组及 DFHack。
没有完整译文的模组名称及内容保留原文，用户自定义小队名称始终原样显示。扩展不修改原始模组 RAW 或世界规则。


[h1]鼠标地图坐标[/h1]
[url=https://steamcommunity.com/sharedfiles/filedetails/?id=3825218095]鼠标坐标模组[/url]在要塞模式显示 X、Y 坐标，支持图形与 ASCII 模式，可在 Shift+F1 菜单中开关。

[h1]地图预览[/h1]
[url=https://steamcommunity.com/sharedfiles/filedetails/?id=3825995422]独立地图预览模组[/url]显示要塞选址处的高程、水系和地貌。订阅并下载后，Shift+F1 显示“地图预览”开关，默认关闭并保存选择。预览精度为选址格。

[h1]搜索与可选语义模型[/h1]

已支持汉化搜索的界面可使用中文、英文、拼音全拼与首字母，并提供输入容错和物品类别匹配。
需要近义匹配时，可订阅 [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3823451988]DFCN 独立离线语义搜索模型[/url]。
核心在启动时自动识别模型，无需联网或在世界模组列表中启用。未安装模型时，普通文字、拼音与容错搜索仍可使用。

[h1]地形蓝图导出[/h1]

[b]Shift+F1[/b] 菜单新增“导出整张地图（全部已知层）”，无需 DFHack。导出完整本地地图和所有含已揭示地形的楼层，保留坐标并标记未知区域，不受镜头或当前楼层影响。
蓝图保存至汉化目录的 [b]blueprints[/b] 文件夹，可导入 dfbluepaint；包含墙、地板、楼梯、斜坡、水、岩浆及植被等地形，不包含建筑、物品或单位。菜单显示导出结果和文件位置。

[h1]开关与刷新[/h1]

[b]Shift+F1[/b]：打开汉化设置菜单；Esc、右键或点击菜单外关闭。四族语言默认中文音译，选择在本次运行及核心重载后保留。

[b]Shift+F10[/b]：开启或关闭汉化，保留当前核心与数据。
[b]Shift+F5[/b]：关闭汉化，再次开启时重新读取核心与数据。
[b]Ctrl+Shift+F10[/b]：刷新配置、词表和规则数据。
[b]Shift+F6[/b]：临时停用或恢复全部扩展数据，并立即重新载入汉化；状态在本次运行中保留。

Windows 同时安装 DFHack 53.16-r2 / r3 时，[b]Shift+F11[/b] 可独立暂停或恢复 DFHack 工具，保留插件配置和状态。关闭时已打开的 DFHack 界面会关闭；已执行的游戏或存档修改不会回滚。DFHack 帮助、控制面板、常用弹窗及本地命令输出支持汉化，可执行命令、快捷键和导出内容保留原文。

[h1]卸载与许可[/h1]

取消订阅不会删除脚本安装、手动安装或生成的文件。工坊安装需移除自己添加的 dfhooks.dll、dfhooks_dfcn.ini 和 dfcn_config.ini；整包安装还需移除汉化 dfcn 目录。保留游戏本体、RAW、存档与个人资料，需要的个人设置可先保存。

普通汉化无需 DFHack，不改写磁盘上的游戏本体、RAW 或存档。
