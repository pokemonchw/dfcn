[h1]DFCN · 矮人要塞简体中文汉化[/h1]

DFCN 是 Byayoi 同人社区的《Dwarf Fortress（矮人要塞）》汉化作品，结合社区译文与本地修订，翻译游戏界面、人物信息、物品描述和传说故事。

[b]适配 Dwarf Fortress 53.16，Windows x64，支持 Steam 版与官网免费版。[/b]
当前版本：[b]53.16-20261010.2[/b]（2026-10-10）。
更新内容见改动说明与订阅目录中的 CHANGELOG.txt。

[url=https://github.com/pokemonchw/dfcn]GitHub 项目主页[/url]
[url=https://github.com/pokemonchw/dfcn/releases/tag/v53.16-20261010.2]Windows 与独立汉化数据下载[/url]

[h1]Windows 工坊安装[/h1]

[b]运行文件位于 DFCN 文件夹。仅订阅不会自动启用汉化。[/b]
[olist]
[*]打开订阅目录：[code]你的 Steam 库目录/steamapps/workshop/content/975370/3811193379/DFCN/[/code]
[*]将其中的 [b]dfhooks.dll[/b] 与 [b]dfhooks_dfcn.ini[/b] 复制到包含 [b]Dwarf Fortress.exe[/b] 的游戏根目录。
[*]INI 第一行应指向订阅目录中 [b]DFCN/dfcn/dfhooks_dfcn.dll[/b] 的实际路径。其余文件保留在订阅目录。
[/olist]
游戏与订阅内容位于同一 Steam 库时，已预填：[code]../../workshop/content/975370/3811193379/DFCN/dfcn/dfhooks_dfcn.dll[/code]
位于不同 Steam 库时，改用实际绝对路径，例如：[code]D:/SteamLibrary/steamapps/workshop/content/975370/3811193379/DFCN/dfcn/dfhooks_dfcn.dll[/code]
[b]第一行只写 DLL 路径，不加引号、不写 key=value，保存为 UTF-8 无 BOM。[/b]

保留完整订阅目录结构。汉化设置位于：[code]DFCN/dfcn/data/runtime/config.ini[/code]
后续工坊更新由 Steam 下载到订阅目录；目录不变时，入口配置继续使用。
旧版整包安装升级时，移除游戏根目录中旧的 [b]dfhooks_dfcn.dll[/b]（若存在）。旧 dfcn 文件夹中的个人配置可自行保留。

[h1]GitHub 安装与汉化扩展[/h1]

GitHub Windows 运行包 [b]DFCN-Windows-x64-minimal.zip[/b] 整包解压到游戏根目录，包括 dfhooks.dll、dfhooks_dfcn.ini 和整个 dfcn 文件夹。
整包安装的设置位于游戏目录的 dfcn/data/runtime/config.ini。

本体自动识别已下载的独立汉化数据扩展；数据包无需在创建世界的模组列表中启用，原始玩法模组按其作者说明使用。本体运行包不内置独立数据包。

[list]
[*][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3815355177]Dwarvemon 汉化数据[/url]
[*][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3815791420]Dwarvemon Beta 汉化数据[/url]
[*][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3815791235]Dwarvemon Entity Type 汉化数据[/url]
[*][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3815791319]Dwarvemon Entity All 汉化数据[/url]
[/list]
Dwarvemon 与 Beta 各有独立完整数据；Entity Type 与 Entity All 翻译各自名称和文明配置简介，生物与物品译文由 Dwarvemon 汉化数据提供。其余 18 个扩展的创意工坊项目维持私密。
没有完整译文的模组名称及内容保留原文，用户自定义小队名称始终原样显示。扩展不修改原始模组 RAW 或世界规则。

[h1]开关与刷新[/h1]

[b]Shift+F10[/b]：开启或关闭汉化，保留当前核心与数据。
[b]Shift+F5[/b]：关闭汉化，再次开启时重新读取核心与数据。
[b]Ctrl+Shift+F10[/b]：刷新配置、词表和规则数据。
[b]Shift+F6[/b]：临时停用或恢复全部扩展数据，并立即重新载入汉化；状态在本次运行中保留。

Windows 同时安装 DFHack 53.16-r2 时，[b]Shift+F11[/b] 可独立暂停或恢复 DFHack 工具，保留插件配置和状态。关闭时已打开的 DFHack 界面会关闭；已执行的游戏或存档修改不会回滚。DFHack 帮助、控制面板、常用弹窗及本地命令输出支持汉化，可执行命令、快捷键和导出内容保留原文。

[h1]卸载与许可[/h1]

取消订阅不会删除手动安装到游戏目录的文件。工坊安装需移除自己添加的 dfhooks.dll 与 dfhooks_dfcn.ini；整包安装还需移除汉化 dfcn 目录。保留游戏本体、RAW、存档与个人资料。

普通汉化无需 DFHack，不改写磁盘上的游戏本体、RAW 或存档。
