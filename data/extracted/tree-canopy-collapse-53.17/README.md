# 地表孤树的树冠泥土地板与伐木塌方

玩家观察到一棵生长在露天地表的独立树木，树冠周围没有地层。树长大后，冠部出现一层泥土地板，砍掉这棵树时发生塌方。

在 Steam Windows 版 53.17 中，当塌方程序移动树枝或嫩枝所在的格子时，它可以依据该坐标的地质材料，在空中写入泥土地板。同一棵树较低的枝条可以承托它。这条路径以部分树格已被判为失去支撑为前提。现有资料没有记录该树生长前后的逐格状态，首次生成整层泥土地板的触发原因仍未确定。

## 从树冠生长到地块下落

| 阶段 | 53.17 中可定位的行为 |
| --- | --- |
| 生长 | 程序先计算树形，再把树体写入地图，随后更新树覆盖的地图列。常规枝条和嫩枝使用独立的地块编号。树冠写入分支识别露天空格 `0x20`。[生长更新](growth_tick.c#L317) · [树冠写入](tree_map_update.c#L2389) · [树格编号](tree-tile-dispatch.tsv#L110) |
| 支撑判定 | 生长和树体移除均可标记地图列，触发支撑重算。支撑程序沿高度扫描，把连续树格计入支撑。塌方分类中，树枝和嫩枝都与空气分属不同类别。[地图列标记](schedule_column.c#L22) · [地块分类](cave_tile_class.c#L120) · [纵向扫描](build_column_spans.c#L68) |
| 泥土地板形成 | 下落函数 `0x1414CB0A0` 分别检查来源格和目标格。命中树体分类时，程序读取坐标记录的地质层材料。如果该材料带有 `SOIL_ANY` 标志，就选取 `0x15C–0x15F` 中的一种泥土地板并写入地图。附近无需有一块实体土可供搬移。[来源格转换](falling_tile.c#L131) · [目标格转换](falling_tile.c#L188) · [地质层查询](geolayer_material.c#L26) · [土壤标志](../../upstream/df-structures/df.matgloss.xml#L17) |
| 停在树上与再次下落 | 下落循环沿同一列逐层向下，遇到属于支撑类别的树格即可停止。砍伐会遍历整棵树，移除树体并更新受影响的地图列。如果一片地板到稳定地形的唯一连接经过这棵树，它随后便会失去支撑。[下落循环](drop_unsupported.c#L491) · [伐木](felling_area.c#L88) · [树体移除后的更新](remove_tree_tiles.c#L646) · [失去支撑的区域](cavern_event.c#L188) |

## 映像与地址
