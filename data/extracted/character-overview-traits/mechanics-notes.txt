概述短词条的作用与生成机制
日期：2026-11-13

来源与范围
本次离线分析当前 Steam 安装的 Dwarf Fortress.exe，PE:6aea05a1:02734000。
映像路径和 SHA-256 见 selection-source.tsv。未读取进程、存档或游戏运行日志。
完整界面更新函数 RVA 0x1a3360，代码至 0x1a70e0；其 unwind 记录至
0x1a721e，尾部含跳转表。概述特征分支为 0x1a3ae9..0x1a4d18。
reference-trait-selection.c 为 Ghidra 12.1.4 实际反编译输出；不是手写伪代码。
函数名是分析标签。手动提供五张原生跳转表的目标；未修改游戏映像。
渲染部分沿用 reference-overview-traits-region.c/.asm 和 native-traits.tsv。

因果方向
角色的身体/心智属性、性格倾向、个人价值观及文化背景 -> 筛选评分 -> 界面摘要。
概述分支读取角色数据，写入 view_sheets_interfacest 的界面缓存：
  +0xc4: trait[6]，类别；+0xdc: trait_id[6]，类别内编号；
  +0xf4: trait_magnitude[6]，排序分数；+0x10c: trait_num，当前条数。
渲染器只把类别与编号转换为颜色、短句。没有以短句为依据反向修改属性的步骤。
文字不是另加一层的属性修正或可叠加增益。实际数值是否用于某项活动，要看该活动
读取对应字段的规则；本分析不据名称推断每项属性对所有工作/行为的具体公式。

显示上限与类别
每次重建先清零 trait_num；依次合并身体属性、心智属性、个人价值观、性格候选。
每个候选按 magnitude 从大到小插入；满 6 条则淘汰末项，计数不再增加。
比较为严格大于才前插，同分保留已有项在前。这不是随机抽取六条，也不是每类配额。
不足六个候选可以少于六条。未入选只是不显示，不删除角色对应字段。
六条来自界面固定数组及代码中的 cmp ...,6，不是截图窗口高度造成的截断。
短句池为 (6 身体属性 + 13 心智属性 + 50 性格倾向 + 33 价值观) * 2 = 204。
每一概念只有高/低两个概述短句，多个详细强弱等级合并到同一个短句。

身体与心智属性的入选与评分
RVA 0x1a42a0..0x1a434c、0x1a4530..0x1a45fb 先读取 value-soft_demotion，
应用现有属性百分比和固定加值修正，并将计算值至少取 0。存在隐藏身份相关的
显示分支时还会与未经该修正的结果取较低分；不能把摘要当作完整真实数值接口。
基准 B 读取 caste+0x1234+28*i（身体）或 caste+0x12dc+28*i（心智）。
同一映像 raw 解析器在 RVA 0x70ca43 / 0x70d333 将 *_ATT_RANGE 的第 4 个数
写入这些位置；七点分布的基准点由此直接确认。相关解析区域保留在
reference-attribute-range-parser-regions.asm。
通常分数 d = 向零截断((用于显示的属性值 A - B) / 20)。
只有 d>=25 或 d<=-25 才加入候选，即相对基准至少高或低 500 点。
方向由 d 的正负决定，最终排序 magnitude=abs(d)。没有在该评分步骤封顶至 100。
仍需进入全体候选前六，才能在概述显示。
标准矮人的 CREATIVITY/PATIENCE/MEMORY raw 第 4 个数均为 1250；因此在这些
raw 生效且无特殊显示修正时，低项候选为 <=750，高项候选为 >=1750。
这是条件举例，并非读取截图角色的精确属性或存档所启用的模组。

性格倾向
50 项 facet 基础值按是否落在 [40,60] 之外筛选，通常 magnitude=abs(facet-50)。
小于 50 为 low，大于 50 为 high。暂时性性格变化还有一条特殊路径：基础值位于
中间区间，但临时变化使描述等级改变时，可加入 magnitude=0 的候选。
所以简化门槛仅适用于没有该特殊情况的普通分支。

价值观
从 soul 的个人 values 向量读取 type 和 strength，并读取文化身份的价值表；没有
文化身份时尝试文明价值表。文化等级边界为 -40/-25/-10/10/25/40。
先构造文化筛除列表，再筛选个人条目，最终入选的标签使用个人条目的 strength。
通常个人强度在 [-10,10] 外才是候选；文化对照也存在让中间值进入候选的分支。
因此不能把 abs(strength)>10 当作独立、充分、无例外的入选条件。
个人值 v 的排序分数为 2*abs(v)+(v>0 ? 1 : 0)。v<0 对应 low，v>=0 对应 high。
文化筛选的精确非对称分支保留在 C/ASM 中；不将它简化为“个人值减文化值”。

截图六项
Disdains friendship / 轻视友情：个人价值观 FRIENDSHIP 的 low。
Not creative / 创造力不足：心智属性 CREATIVITY 的 low。
Sickly / 容易生病：身体属性 DISEASE_RESISTANCE 的 low，不是当前患病诊断。
Good memory / 记忆力好：心智属性 MEMORY 的 high，不代表已达到上限。
Impatient / 缺乏耐心：心智属性 PATIENCE 的 low，不是另一个独立性格惩罚。
Values eloquence / 看重口才：个人价值观 ELOQUENCE 的 high，不增加语言属性。

边界
本次确认概述词条的筛选、排序与渲染。没有反编译所有出生属性随机分布、成长上限、
技能训练、疾病、需求与行为消费者；不能以本结果声称这些系统的全部公式已确认。
